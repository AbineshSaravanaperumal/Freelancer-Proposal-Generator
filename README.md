# ProposalAI — Freelancer Proposal Generator

AI-powered proposal generator for freelancers on Upwork and Fiverr.
Paste a job description, get a personalised 120-180 word proposal in under 10 seconds.

**[→ Live Demo](https://freelancer-proposal-generator-krx9imyf9.vercel.app)**

![ProposalAI Screenshot](https://github.com/AbineshSaravanaperumal/Freelancer-Proposal-Generator/issues/1#issue-4355366638)

## The Problem
Freelancers write the same proposal 20 times a day — manually, from scratch.
Most proposals are generic and get ignored. This tool reads the job and writes
a personalised, high-converting proposal instantly.

## What It Does
- Generates personalised proposals tailored to each job description
- 3 tone modes: Professional, Friendly, Bold
- Tracks proposal history per session
- Free tier: 5 proposals/month — upgrade prompt built in
- Zero backend — runs entirely in the browser

## Tech Stack
- Vanilla HTML/CSS/JS — no framework
- Groq API (llama-3.3-70b-versatile) — free, fast inference
- Deployed on Vercel
